Wardogs - mortar &amp; artillery Calculator 
🎯 An unofficial mortar and artillery fire calculator for the tactical shooter WARDOGS. Range, azimuth, and elevation angle (in mils)—just two clicks on a 16×16 km map.
🗺️ Interactive map — tile-based zooming and panning
📐 Targeting calculations — range, azimuth, and elevation (in mils)
💥 Two modes - mortar (684 m) and artillery (2679 m)
🏜️Two locations – Bakurani and Ozeti (16×16 km)
✏️ Drawing tools - pen, ruler, marker, eraser
🗼 Landmarks — towers and zones on the Bakurani map
🔗 Coordinate sharing — link for quick sharing
💾 Auto-save — settings and points saved to localStorage
🌓Themes - dark and light
🌍 7 languages ​​— ru, en, de, fr, uk, tr, zh
📱 Mobile-friendly — responsive design for all screen sizes
